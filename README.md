# ghost-media

An algorithmic **music-video generator**. It analyzes a library of source footage
and a DJ set's audio, then automatically selects and assembles clips that sync to
the music's energy, tempo, color temperature, and mood — producing a finished
`.mp4` with no manual editing.

The project is two layers:

| Layer | What it is | Lives in |
|-------|------------|----------|
| **Toolkit** (`media_analyzer/`) | Reusable, pip-installable analysis library + `media-analyzer` CLI. Turns any audio/video file into ML-friendly JSON (BPM/beats/key/energy/sections for audio; scenes/motion/color/brightness for video). | `media_analyzer/`, `pyproject.toml`, `setup.sh`, `examples/` |
| **Pipeline** (root scripts) | The application that consumes that JSON: deep DJ-set audio analysis, vision-model enrichment, lyrics extraction, and the clip-matching **assembler** that scores footage against audio and renders the video. | the `*.py` scripts at the repo root |

> **Heads-up:** the generated data (`*.analysis.json`, `enriched/`, `text_flags/`,
> `sets/`, `demucs_output/`, rendered media) is **gitignored** — this repo holds
> code, docs, and small example outputs only. The data is regenerated by running
> the pipeline.

## How it works

```
Source footage library                DJ set audio
(/Volumes/archive/.../visuals)        (/Volumes/archive/.../sets)
        │                                     │
        ▼                                     ▼
1. analyze_visuals_library.py        2. analyze_dj_set_deep.py
   (scenes, motion, color,              (7-band energy, HPSS, onsets,
    brightness  →  .analysis.json)       chroma, BPM, phrases  →  .deep-analysis.json)
        │                                     │
        ▼                                     ▼
3. enrich_analyses.py               2b. extract_lyrics.py
   (qwen2.5vl vision tags                (Demucs vocal isolation +
    →  enriched/*.enriched.json)          Whisper transcription  →  .lyrics.json)
        │                                     │
        ▼                                     │
4. scan_text_fast.py                          │
   (flag on-screen English text)              │
        │                                     │
   4b. generate_clip_embeddings.py            │
        (CLIP per-scene vectors)              │
        │                                     │
   4c. flag_quality.py                         │
        (black/blown/frozen/dup → quality)    │
        │                                     │
        └──────────────┬──────────────────────┘
                       ▼
              5. assemble_v2.py
                 build scene DB (~19k scenes) → extract phrase features →
                 adaptive phrase merge → score + select clips → ffmpeg render
                       │
                       ▼
                Music Video (.mp4)
```

Two side tools sit on the same data: **`query_scenes.py`** searches the scene
corpus in natural language over the CLIP embeddings, and **`enrich_analyses.py
--backend claude-cli`** runs vision enrichment on your Claude subscription instead
of the local model.

See **[ARCHITECTURE.md](ARCHITECTURE.md)** for the full data flow, JSON schemas,
scoring weights, and diversity parameters, **[AGENTS.md](AGENTS.md)** for a
contributor/agent guide, and **[lessons.md](lessons.md)** for engineering lessons
and gotchas.

## Quick start

### Prerequisites
- Python 3.10+
- [FFmpeg](https://ffmpeg.org/) — `brew install ffmpeg`
- [Ollama](https://ollama.com/) with `qwen2.5vl:7b` — for vision enrichment + text detection
- [Demucs](https://github.com/facebookresearch/demucs) + [Whisper](https://github.com/openai/whisper) — for lyrics extraction (`pip install demucs openai-whisper`)
- Source footage on the external archive drive (see paths in `ARCHITECTURE.md`)

### Install the toolkit

```bash
./setup.sh                 # creates .venv and installs the media-analyzer package
source .venv/bin/activate
```

This installs the `media-analyzer` CLI (audio/video analysis). See
**[docs/toolkit.md](docs/toolkit.md)** for its full CLI reference and JSON schema.

### Run the pipeline

```bash
# 1. Analyze the footage library  → *.analysis.json (output dir: ~/Downloads/ghost-media)
python3 analyze_visuals_library.py

# 2. Deep audio analysis of a DJ set
python3 analyze_dj_set_deep.py --input "/path/to/set.mp3" --tracklist tracklist.txt

# 3. Vision enrichment (Ollama running)        4. Text scan
python3 enrich_analyses.py                      python3 scan_text_fast.py

# 4b. (optional) lyrics
python3 extract_lyrics.py --set <set-name>

# 5. Assemble the music video
python3 assemble_v2.py --set <set-name>
```
